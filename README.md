# Практика 3. Вариант 21: Ассемблер и интерпретатор для УВМ

## Общее описание
Проект представляет собой ассемблер и интерпретатор для учебной виртуальной машины (УВМ). 
На данном этапе (Этап 1) реализован CLI-ассемблер, который транслирует текстовое представление программы на языке ассемблера (в формате YAML) во внутреннее представление и генерирует бинарный файл.

## Спецификация УВМ (Вариант 21)
Виртуальная машина поддерживает 4 команды. Команды имеют размер 3 или 5 байт. Поля операндов распределены по битам.

| Команда | Код (A) | Размер (байт) | Поле B | Поле C |
|---|---|---|---|---|
| `load_const` | 14 | 5 | Константа (биты 4–25) | Адрес (биты 26–32) |
| `read` | 0 | 3 | Адрес (биты 4–10) | Адрес (биты 11–17) |
| `write` | 4 | 5 | Адрес (биты 4–10) | Адрес (биты 11–35) |
| `sqrt` | 9 | 3 | Адрес (биты 4–10) | Адрес (биты 11–17) |

## Спроектированный язык ассемблера (YAML)
Программа на языке ассемблера представляет собой YAML-список. Каждый элемент списка описывает одну команду.
Для задания команды используются три ключа:
- `name` — название команды (`load_const`, `read`, `write`, `sqrt`).
- `b` — значение поля B (для `load_const` это сама константа, для остальных — адрес).
- `c` — значение поля C (адрес).

**Пример программы:**
```yaml
- name: load_const
  b: 163
  c: 2
- name: read
  b: 14
  c: 40
- name: write
  b: 49
  c: 168
- name: sqrt
  b: 20
  c: 74
